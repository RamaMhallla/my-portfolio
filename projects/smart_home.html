Integrated Smart Home Platform: AI Energy Prediction over Heterogeneous IoT Networks

IoT project, University of Calabria Oct 2025 – May 2026 Completed

My contributions:

  • Integrated the Flutter application, BLE communication and MQTT with the Raspberry Pi edge gateway
  • Developed the Flutter mobile application for real-time monitoring and smart home control
  • Collaborated on integrating the AI energy prediction module into the overall system
  • Designed and implemented the secure BLE communication between the Flutter application and the smart lock

Overview

A working smart home platform that brings together several IoT communication technologies, AI-based energy prediction and secure access control. Sensors and actuators in three rooms communicate over Zigbee and LoRaWAN with a Raspberry Pi 5 edge gateway, the smartphone talks to the smart lock over BLE, and a Bi-LSTM model forecasts household energy use to support appliance scheduling and heating control. A Flutter app provides real-time monitoring, remote control and alerts.

Motivation

Existing smart-home energy studies tend to focus on one part of the problem: a prediction model (Random Forest, LSTM, or comparisons of forecasting methods) or a framework that is described but not built. This project set out to integrate heterogeneous IoT communication, AI prediction and security into one working platform.

Design Decisions

  • Zigbee: low-power mesh network for reliable indoor sensor communication
  • LoRaWAN: long-range link for distant nodes such as the garage
  • BLE: short-range link between the smartphone and the smart lock
  • Raspberry Pi 5: edge gateway for protocol integration and local processing
  • MQTT: lightweight publish/subscribe messaging for real-time communication
  • Bi-LSTM: time-series forecasting of energy use to drive optimisation

System Architecture

Rooms 1 and 2 connect over Zigbee; the garage (room 3) uses LoRaWAN and BLE. The gateway publishes data over MQTT to the Flutter app and feeds the Bi-LSTM energy prediction.

The physical testbed: Raspberry Pi gateway, three room nodes with LoRaWAN and Zigbee modules, the ESP32 smart lock module, and motors standing in for heaters.

Engineering Challenges

Challenge Solution
Heterogeneous protocols Unified Zigbee, LoRa, BLE and MQTT through the Raspberry Pi gateway
Real-time communication MQTT publish/subscribe messaging between gateway and app
Smart lock security Secure BLE authentication between the app and the lock
LoRa frequency mismatch Validated the hardware configuration and communication experimentally
AI integration Connected the prediction module to the edge gateway for real-time inference

Results

  • Real-time sensor data synchronised to the app over MQTT
  • Remote control of lights and heaters in each room
  • BLE smart lock: a matching PIN triggers the garage unlock, and a confirmation is sent to the gateway over LoRa
  • AI-based alerts and notifications in the app

From Smart Home to Secure Smart Lock

The IoT Security course made it clear that the smart lock was the most safety-critical device in the platform. It was then redesigned with authentication and end-to-end encryption and tested against real attacks: see the Secure Smart Lock project.
